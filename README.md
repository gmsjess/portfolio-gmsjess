# 💻 Portfólio Pessoal - Jéssica Gomes

Bem-vindo(a) ao repositório do meu **Portfólio Pessoal**! Este projeto foi desenvolvido para apresentar minha trajetória, minhas habilidades técnicas, minhas redes de contato e disponibilizar o meu currículo para download.

---

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da aplicação.
- **CSS3:** Estilização moderna, animações customizadas em `@keyframes`, variáveis CSS e regras de responsividade (*Media Queries*).
- **JavaScript (ES6+):** Lógica para alternância de tema (Dark/Light), controle do menu mobile e efeito no cabeçalho ao rolar a página.
- **Google Fonts:** Tipografia `Poppins`.

---

## ✨ Funcionalidades

- 🎭 **Efeito de Digitação (CSS Animations):** Animação estilizada ao carregar o nome e o título principal na tela de início.
- 🌓 **Modo Claro e Escuro (Light/Dark Theme):** Botão para alternar o tema visual da página dinamicamente.
- 📱 **Menu Mobile Responsivo:** Navegação adaptada para smartphones com menu hambúrguer interativo.
- 📜 **Download de Currículo:** Botão com ação direta para baixar o arquivo do currículo em formato PDF.
- 🔗 **Links para Redes Sociais:** Acesso direto ao GitHub, LinkedIn e Instagram.
- 📍 **Informações de Contato:** Seção direcionada para comunicação via e-mail e informações regionais.
